# Kevara AI website

A viewable backup of the Kevara AI agency website, with responsive styling, a rotating particle globe, animated service visuals and interactive customer journeys.

## Open the website

Once GitHub Pages is enabled, the website is served at https://travionthomas685-ctrl.github.io/kevara-website/

In repository Settings > Pages, choose Deploy from a branch, select main and /(root), then Save. Wait for the Pages deployment to finish. No build step is needed.

## Enquiries

This backup copy opens an email draft addressed to t.thomas@kevarallc.com. It does not connect to the production enquiry database or provide a private inbox. Send the draft from your email application to deliver an enquiry.

## Recovery

Download the repository as a ZIP or clone it to keep a copy of the built website. Serve the files with any static web server. Asset paths are relative so the site can be hosted under this repository path.

The complete application source and backend restoration instructions are retained separately in the owner's private agency repository. No backend credentials, database records or private agency files are included here.

The main site's domain is https://kevarallc.com/. This backup has a noindex directive so it does not compete with the main site in search.
